# cowboy-banner в Windows

Подробная документация по Windows-части. Общее описание и Linux — в
[README.md](../README.md) корня репозитория.

## Быстрый старт

| Что сделать | PowerShell | cmd |
|---|---|---|
| Меню тем сейчас | `Show-CowboyMenu` | `set COWBOY_BANNER=menu` + `call "%USERPROFILE%\bin\cowboy.cmd"` |
| Ещё одна картинка | `cowboy` | открыть новое окно |
| Выключить навсегда | `setx COWBOY_BANNER none` | `setx COWBOY_BANNER none` |
| Включить обратно | `setx COWBOY_BANNER ""` | `setx COWBOY_BANNER ""` |
| Сменить тему навсегда | `setx COWBOY_THEME ocean` | `setx COWBOY_THEME ocean` |
| Сменить тему в этом окне | `$env:COWBOY_THEME = 'cyber'` | `set COWBOY_THEME=cyber` |
| Случайная тема | `setx COWBOY_THEME any` | `setx COWBOY_THEME any` |
| Вернуть подсказки в баннер | `setx COWBOY_HINT on` | `setx COWBOY_HINT on` |

После `setx` окно надо **закрыть и открыть заново** - переменная читается при
старте.

## Переменные

Работают одинаково в PowerShell и cmd (в PowerShell с префиксом `$env:`).

### COWBOY_THEME - какую тему рисовать

| Значение | Тема | Картинок |
|---|---|---|
| `wildwest` | Дикий Запад (по умолчанию) | 4 |
| `space` | Космос | 2 |
| `cyber` | Киберпанк | 2 |
| `ocean` | Океан | 2 |
| `any` | случайная из всех | 10 |
| `menu` | показать меню тем | - |
| любое другое | откат на `wildwest` | 4 |

### COWBOY_BANNER - что показывать

| Значение | Результат |
|---|---|
| не задана (пусто) | рисовать картинку |
| `menu` | показывать меню тем вместо картинки |
| `none` | не выводить абсолютно ничего |
| `ascii` | картинка без псевдографики (ASCII) |
| `plain` | картинка без цвета |
| `off` | старое имя, работает как `menu` |

### COWBOY_HINT - служебные строки

| Значение | Результат |
|---|---|
| `on` / `1` / `yes` / `true` | внизу баннера появляется подсказка и метка `[тема]` |
| не задана | только картинка, приветствие и поговорка |

### Служебные (cmd)

| Переменная | Результат |
|---|---|
| `COWBOY_ALWAYS=1` | показывать баннер и в `cmd /c` (по умолчанию - только в интерактивном окне, чтобы не портить вывод скриптов) |
| `COWBOY_CMD` | синоним `COWBOY_BANNER` |

## Команды PowerShell

| Команда | Что делает |
|---|---|
| `cowboy` | напечатать ещё одну картинку (алиас на `Show-CowboyBanner`) |
| `Show-CowboyBanner` | то же самое |
| `Show-CowboyMenu` | напечатать меню тем |
| `Disable-CowboyBanner` | выключить до конца сессии |
| `Enable-CowboyBanner` | включить обратно в этой сессии |
| `Get-CowboyBanner` | вернуть текст баннера строкой (без вывода) |
| `Get-CowboyBanner -Plain` | то же без цвета |
| `Get-CowboyTheme` | узнать активную тему |

## Куда ставится

| Что | Путь |
|---|---|
| Профиль PowerShell | `%USERPROFILE%\Documents\WindowsPowerShell\cowboy-profile.ps1` |
| Основной профиль (подключает первый) | `%USERPROFILE%\Documents\WindowsPowerShell\profile.ps1` |
| Баннер для cmd | `%USERPROFILE%\bin\cowboy.cmd` |
| Автозапуск cmd | `HKCU\Software\Microsoft\Command Processor\AutoRun` |
| Политика выполнения | `RemoteSigned`, область `CurrentUser` |

`windows\install.ps1` делает всё это сам и не трогает ваш основной профиль:
в него добавляется блок с пометками, который легко вырезать
(`windows\uninstall.ps1` делает это при удалении).

## Если что-то не работает

| Симптом | Причина | Решение |
|---|---|---|
| `не является внутренней или внешней командой` | забыли `set` в cmd | `set COWBOY_BANNER=menu` |
| в PowerShell `set X=off` не работает | `set` = `Set-Variable`, не переменная окружения | `$env:X = 'off'` или `setx` |
| поменял, а ничего не изменилось | `setx` действует только в новых окнах | закрыть и открыть окно |
| в уже открытом окне пусто | автозапуск отработал при открытии | новое окно или `Show-CowboyMenu` |
| картинка есть, цвета нет | консоль не поддерживает ANSI | `setx COWBOY_BANNER plain` |
| кракозябры вместо рамок | кодировка консоли не cp866 | `setx COWBOY_BANNER ascii` |
| лишний пробел в значении | `set X=off ` даёт `"off "` | обрезается автоматически, но лучше не добавлять |
| в выводе скрипта появился баннер | работал `cmd /c` с `COWBOY_ALWAYS` | убрать `set COWBOY_ALWAYS=1` |
| PowerShell стартует медленнее | профиль ~45 КБ | `setx COWBOY_BANNER none` |

## Технические заметки

- **Политика выполнения.** Для работы профиля нужна `RemoteSigned` (область
  CurrentUser): локальные .ps1 разрешены, скачанные из интернета - нет.
  Откатить: `Set-ExecutionPolicy -Scope CurrentUser Undefined`.
- **cmd не умеет читать .cmd с UTF-8.** Если после многобайтного символа
  ломается позиция чтения, строки рассыпаются на команды. Поэтому
  `cowboy.cmd` сохранён в однобайтовой cp866 - это единственный надёжный
  вариант. Псевдографика, кириллица и ANSI-цвета в cp866 есть, а вот `«»`,
  `—`, `▲` (0x1E) - нет: их заменяет генератор, а при несовпадении
  кодировщик падает с ошибкой, а не молча рисует мусор.
- **Случайность.** `[Random]::new()` без сида в .NET Framework берёт
  `Environment.TickCount` с грубым разрешением - два процесса подряд
  получали одну последовательность. Поэтому сид явный, через GUID. Прошлый
  выбор хранится в `%TEMP%\cowboy-banner.state`, поэтому соседние запуски не
  повторяют одну картинку.
- **Скорость.** Старт PowerShell: 112 мс без профиля → 233 мс с картинкой.
  Сама отрисовка ~50 мс, остальное - разбор 45 КБ профиля.
- **Консоль.** При первом запуске профиль проверяет, умеет ли консоль показать
  всю псевдографику, и при необходимости переключает вывод в UTF-8.
